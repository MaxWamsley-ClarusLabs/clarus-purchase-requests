# Ledger quiz for bookkeepers

Eight questions on `docs/LEDGER_QUICK_START.md` and `docs/SOP.md` Part D. Pass mark: 7 of 8. The employee quiz is `docs/TRAINING_QUIZ.md`; this one is separate, for the people in the Purchase Bookkeepers group. Same format as that file (question, four choices, correct letter, feedback, SOP section), so it can be turned into a Microsoft Form the same way. It is a draft for Max to approve before it is used.

### Q1
Question: You select five lines and choose Mark Posted, but one of them has no class. What happens?
A. Four lines are posted and the fifth is skipped.
B. None of the five is posted, and the message names the line that needs a class.
C. All five are posted, and the fifth is flagged for later.
D. The app chooses a class for the fifth line and posts all five.
Correct: B
Feedback: Not quite. Posting is all or nothing, and QuickBooks needs a class on every line. See SOP: Working through it.
SOP section: D2

### Q2
Question: The account list opens with the heading "Used for this vendor before". What does that mean?
A. The app has already filled in that account for you.
B. A bookkeeper posted that account the last time for the same vendor, so it is shown near the top.
C. The vendor is approved by Clarus.
D. The account must be used for this vendor.
Correct: B
Feedback: Not quite. The layers only set the order of the list. Nothing is filled in, and you always make the choice. See SOP: How the account and class boxes work.
SOP section: D3

### Q3
Question: A line is Posted and you notice the wrong class. What do you do?
A. Change the class in the box; Posted lines can be edited.
B. Delete the request and start again.
C. Open the Posted tab, tick the line, choose Set back to Not posted, change the class, then post it again.
D. Leave it and add a note; the class cannot be changed.
Correct: C
Feedback: Not quite. Account and class are locked on a Posted line. Set it back to Not posted, change it, and post it again. A note can be written at any time. See SOP: Working through it.
SOP section: D2

### Q4
Question: A Posted line shows a red note, "Changed since posted: was $120.00, now $150.00". What does it mean and what do you do?
A. The vendor changed; nothing to do.
B. The line's amount changed after it was posted, so QuickBooks may no longer agree. Check QuickBooks, then set the line back and post it again, or add a note.
C. The receipt is missing; upload it.
D. The line was posted twice; delete one.
Correct: B
Feedback: Not quite. The app recorded the amount when you posted. If the line now has a different amount, it warns you. See SOP: Warnings.
SOP section: D2

### Q5
Question: You want to give twelve lines the same class. What is the quickest correct way?
A. Open each line and choose the class.
B. Tick the twelve lines, choose the class in the bar that appears, and choose Apply to 12. Posted lines are left out, and only what you choose is changed.
C. Download Excel, change the class there, and upload it.
D. Ask Max to change the lists in SharePoint.
Correct: B
Feedback: Not quite. Apply to selected changes the account, the class or both for every ticked line that is not Posted. See SOP: Apply to selected lines.
SOP section: D2

### Q6
Question: A line has an amber "Administrator decides" tag. What should you do before posting it?
A. Post it with any account; it can be fixed later.
B. Wait for Max to say which account it should have (for example Equipment 6175 or Fixed Assets 1415), then choose it.
C. Delete the line.
D. Choose the class only; the account is not needed.
Correct: B
Feedback: Not quite. For Equipment and Other lines, the account depends on a decision Max makes. See SOP: What the Ledger shows.
SOP section: D1

### Q7
Question: A receipt link marked "request folder" stops working. Why?
A. The receipt was deleted.
B. It is an older request whose link points to its request folder, and that folder was filed under its year. Newer requests link to the permanent receipt archive.
C. You need a different password.
D. The vendor withdrew the file.
Correct: B
Feedback: Not quite. Receipts packaged after the archive existed are copied to Purchase_Receipts, which does not move when the request folder is filed. See SOP: Receipts and the Excel download.
SOP section: D4

### Q8
Question: The Ledger was damaged one night and some lines lost their account and class. Where is the safety copy?
A. Nowhere; the Ledger exists only in the app.
B. In Accounting, Purchases, Ledger_Backups: a new dated CSV and Markdown copy is saved every night and never overwritten.
C. In your email inbox.
D. In QuickBooks, under Reports.
Correct: B
Feedback: Not quite. A second flow saves the whole ledger every night at 02:30 Central time. See SOP: The nightly backup.
SOP section: D6
